# Cloudflare Pages —— ppanel-admin-web（管理端）

## 1. 创建项目

1. Cloudflare Dashboard → **Workers & Pages** → **Create** → **Pages** → **Connect to Git**。
2. 选择包含 [`frontend/`](../../../frontend) 的仓库（若 frontend 是独立仓库则直接用；若为 ppanel2 整体仓库，根目录填 `frontend`）。
3. 项目名：`ppanel-admin-web`。

## 2. 构建配置

| 配置项 | 值 |
|---|---|
| 框架预设 | 无（不选预设） |
| 根目录 | `frontend`（若仓库根即 frontend/package.json 所在则留空） |
| 构建命令 | `bun install --frozen-lockfile && bun run build --filter=ppanel-admin-web` |
| 构建输出目录 | `apps/admin/dist` |
| Node 版本 | 20（`NODE_VERSION=20`） |

> 说明：`--filter=ppanel-admin-web` 由 turbo 解析，仅构建该包及其 workspace 依赖（`@workspace/ui` 等）。

## 3. 环境变量（Production）

```text
VITE_API_BASE_URL=https://ppapi.lightree.uk
VITE_API_PREFIX=
VITE_CDN_URL=https://cdn.jsdmirror.com
VITE_TUTORIAL_DOCUMENT=true
NODE_VERSION=20
```

> 关键：后端已内置**白名单 CORS**（合法来源见 `ppanel-cors` ConfigMap，支持热重载），不再使用
> Worker 网关/Caddy；前端**直连** `https://ppapi.lightree.uk` 即为 API 域名（后端路由 `/v1/...`，
> 见 [`frontend/packages/ui/src/lib/request.ts`](../../../frontend/packages/ui/src/lib/request.ts)）。
> `VITE_API_PREFIX` **必须留空**——后端没有 `/api` 前缀路由，且已无 Worker 剥除前缀。

## 4. 绑定自定义域

项目 **Custom domains** → **Set up a custom domain** → 输入 `xxadmin.lightree.uk` → 激活。

## 5. 说明

- **无需** `_redirects` / Pages Functions 反代（前端直连 `ppapi.lightree.uk`，CORS 由后端处理）。
- SPA 路由回退：若子路由刷新 404，可在项目根放 `public/_redirects`：
  ```text
  /*  /index.html  200
  ```
  （该规则仅处理静态资源回退，不影响 API 调用。）
